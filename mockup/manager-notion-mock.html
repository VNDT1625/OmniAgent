C4 Model

C4 là cách mô tả kiến trúc phần mềm theo bốn mức: Context, Container, Component và Code. Mỗi mức zoom sâu dần vào hệ thống.

💡
Mức Component thường chứa [[Class Diagram]] để mô tả chi tiết.

Bốn mức

  • Context — hệ thống & người dùng/đối tác bên ngoài.
  • Container — ứng dụng, service, database.
  • Component — khối bên trong một container — xem [[Class Diagram]].
  • Code — chi tiết lớp/hàm.

Liên quan: [[REST vs gRPC]] khi chọn giao tiếp giữa container.
